# Laboratorio AEAD

Esta carpeta reúne el frontend, los dos microservicios y el piloto reproducible en Docker.

Con Docker activo, ejecuta desde esta carpeta.

```sh
./iniciar.sh
```

Abre el [laboratorio](http://localhost:8080/). El comando levanta el frontend y ambos microservicios con AES-128-GCM por defecto.

Consulta las [instrucciones del piloto y los otros modos](experimentos/microservicios/README.md).
